# Changelog

All notable changes to skills in this repository are documented here.

## [v0.1.0] - 2026-09-04

### Added
- Standardized 4-file test harness across all skills (`input-good.md`, `input-risky.md`, `expected-behavior.md`, `prompts.md`).
- **`mmm-concise-brief`** (v0.1): Zero-fluff, ADHD-friendly MMM executive briefs with strict < 250 word budget, anti-hallucination metric grounding, and discrete channel action taxonomy.
- **`sow-review`** (v0.1): Scope clarity, acceptance events, IP terms, client dependencies, and redlines.
- **`contract-risk-review`** (v0.1): Commercial liability caps, indemnities, SLA penalties, and termination mechanics.
- **`mmm-model-review`** (v0.1): Post-estimation MMM audit, adstock half-lives, Hill saturation, autocorrelation.
- **`meridian-mmm-build`** (v0.1): Google Meridian model spec, GeoLift priors, and MCMC execution runner.
- **`mmm-model-design`** (v0.1): Bayesian MMM architecture design and prior planning.
- **`azure-ml-deployment-review`** (v0.1): Managed online endpoints, autoscaling rules, private links, container sizing.
- **`powerbi-forecasting-handoff`** (v0.1): Star-schema data models, DAX time-intelligence, incremental refresh, RLS.
- Upgraded `scripts/create_skill.py` CLI scaffolding tool.
- Upgraded `scripts/lint_skills.py` quality gate linter with 100% test coverage.
- Antigravity workspace integration `.agents/skills/claude-skill-builder/`.
