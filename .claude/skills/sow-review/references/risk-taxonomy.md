# SOW Risk Taxonomy

Use this taxonomy to classify and quantify contractual and delivery hazards.

## 1. Scope & Deliverables Risks
- **Creep by Adjective**: Words like "all", "any", "complete", "fully integrated", "end-to-end" without boundary conditions.
- **Unbounded Training / Support**: Commitments to "train the team" without seat limits, hour caps, or fixed delivery formats.
- **Third-Party Integrations**: Committing to integrate with customer legacy systems without pre-verified API documentation or sandboxes.

## 2. Customer Dependencies & Data Access Risks
- **Data Readiness Gap**: Assuming customer data is "clean, labeled, and formatted" without a preliminary data audit stage.
- **Environment & Credentials Blockers**: Failure to state that project timeline automatically shifts day-for-day when customer provisioning is delayed.
- **SME Availability**: No designated Single Point of Contact (SPOC) or required SLA on client SME response time.

## 3. Commercial, Warranty & IP Risks
- **Uncapped Warranty**: Offering 6-12 months of free bug fixes on custom code exposed to user configuration changes.
- **Background IP Contamination**: Failing to explicitly carve out pre-existing frameworks, libraries, and proprietary accelerators from client work-for-hire assignment.
- **Fixed-Fee with Variable Scope**: Fixed price combined with undefined feature requirements.
